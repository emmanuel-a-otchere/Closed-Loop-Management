# CLAM API Examples

Runnable examples for the CLAM REST API. These assume the service is running
at `http://localhost:8000`.

## Health

```bash
curl http://localhost:8000/health
# {"status":"ok"}
```

## OpenAPI document

```bash
curl http://localhost:8000/openapi.json | jq '.info.title, .openapi'
```

## Create a decision model (OODA)

```bash
curl -X POST http://localhost:8000/api/v1/decisionModel \
  -H "Content-Type: application/json" \
  -d '{
    "kind": "OODA",
    "name": "default-ooda",
    "observe":  {"id": "11111111-1111-1111-1111-111111111111"},
    "orient":   {"id": "22222222-2222-2222-2222-222222222222"},
    "decide":   {"id": "33333333-3333-3333-3333-333333333333"},
    "act":      {"id": "44444444-4444-4444-4444-444444444444"}
  }'
```

## Create a decision model (MAPE)

```bash
curl -X POST http://localhost:8000/api/v1/decisionModel \
  -H "Content-Type: application/json" \
  -d '{
    "kind": "MAPE",
    "name": "default-mape",
    "monitor":  {"id": "55555555-5555-5555-5555-555555555555"},
    "analyze":  {"id": "66666666-6666-6666-6666-666666666666"},
    "plan":     {"id": "77777777-7777-7777-7777-777777777777"},
    "execute":  {"id": "88888888-8888-8888-8888-888888888888"}
  }'
```

## Create a closed loop

```bash
curl -X POST http://localhost:8000/api/v1/closedLoop \
  -H "Content-Type: application/json" \
  -d '{
    "name": "cpu-thermal-loop",
    "description": "Closed loop that monitors CPU temperature and adjusts fan speed.",
    "decisionModelRef": {"id": "<decision-model-uuid>", "kind": "OODA"}
  }'
```

## List closed loops

```bash
curl "http://localhost:8000/api/v1/closedLoop?page=1&pageSize=20"
```

## Get a single closed loop

```bash
curl http://localhost:8000/api/v1/closedLoop/<id>
```

## Patch a closed loop

```bash
curl -X PATCH http://localhost:8000/api/v1/closedLoop/<id> \
  -H "Content-Type: application/json" \
  -d '{
    "description": "Updated description."
  }'
```

## Read state

```bash
curl http://localhost:8000/api/v1/closedLoop/<id>/state
# {"state": "designed"}
```

## Activate

```bash
curl -X POST http://localhost:8000/api/v1/closedLoop/<id>/state \
  -H "Content-Type: application/json" \
  -d '{"targetState": "active"}'
```

## Pause

```bash
curl -X POST http://localhost:8000/api/v1/closedLoop/<id>/state \
  -H "Content-Type: application/json" \
  -d '{"targetState": "paused"}'
```

## Retire

```bash
curl -X POST http://localhost:8000/api/v1/closedLoop/<id>/state \
  -H "Content-Type: application/json" \
  -d '{"targetState": "retired"}'
```

## Delete a closed loop

```bash
curl -X DELETE http://localhost:8000/api/v1/closedLoop/<id>
# 204 No Content on success, 404 if not found.
```
